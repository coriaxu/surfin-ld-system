# Surfin 学习发展系统

用于培训记录、AI 内容、金融百科、预算与开销、项目进展和成果报告管理。工作总览、月度总结和年度总结从模块记录自动汇总，无需重复登记。

## 当前版本

纯静态站点，部署在 GitHub Pages。**数据是公开的**：仓库公开，`user-data.json` 可以匿名下载；登录页口令写在源码里，只是一道门帘。2026-11-10 徐老师确认接受数据公开，删除了从未部署的私有服务（`server/`、`assets/secure-client.js`，需要时从 git 历史找回）。备注里不写不宜公开的内容。

- 界面：`index.html`、`assets/workbench.*`、`assets/workflow.*`
- 设计语言「明账」：颜色、字体、圆角令牌只在 `tools/tokens.py` 里改，运行 `python3 tools/tokens.py` 生成 `assets/tokens.css` 并校验对比度；外观切换 `assets/appearance.js`（浅色／深色／跟随系统 × 晴空蓝、湖光青、鸢尾紫，偏好只存本浏览器）；改版样式与交互 `assets/mingzhang.*`（记一笔、手机底栏、汇报排版、明账 2.0 首屏柔光与玻璃数字面板）；首屏迷你趋势与数字滚动 `assets/hero.js`。Claude Design System「学习发展 · 明账」与这里同源，改令牌后用 `--json` 输出 tokens.json 同步过去。
- 期间汇总与导出：`assets/ld-report.js`、`assets/report-export.js`
- 看得见的口径：`assets/ld-insight.js`（纯计算，复用期间汇总）、`assets/insight-ui.js`、`assets/insight.css`。录入培训时实时显示“保存后会这样计入”，并提醒同日同名、项目名写法不一致、单场过长和分享月合并；首页每张指标卡都有“怎么算”；录入抽屉写明改动保存在哪里，未开启同步时顶部显示“仅本浏览器 · 未同步”。
- 数据与同步：`assets/ld-domain.js`、`assets/ld-sync.js`
- 验收清单：`ProjectDocs/功能迭代验收.md`

## 本地验证

使用 Node.js 22 或更高版本，无需安装服务器依赖。

```sh
node --test tests/*.test.*
python3 -m http.server 8080
```

静态预览沿用现有 GitHub 数据读取路径。测试新增、编辑、删除时使用独立测试数据和浏览器来源，勿对正式记录做试验。

## 静态站点使用

通过现有 GitHub Pages 地址进入后，工具菜单提供同步设置、JSON 备份、备份码、导入与主题选项。只读浏览不需要 GitHub Token；静态模式中的编辑仅先保存在当前浏览器，只有已配置同步的管理员才能推送云端。共享访问口令不等同于服务器身份验证。

同步冲突时先导出本机 JSON 副本，再从云端拉取并核对冲突记录。不要通过反复强推解决冲突。Excel 和 PDF 是交付格式；完整迁移使用 JSON 备份。预算、开销和各内容模块保留原始记录，汇总页面不另存一套账。

## 数据口径

- 首页可切换月度和年度累计，保持原有卡片排版；所选月份在首页与总结页间保留。年度累计从所选年份的 1 月 1 日统计至截止月份月底；当月只统计到上海时区当天，不纳入未来培训或发布记录。历史年度可选至 12 月。
- 月度／年度总结与 PDF、Excel 共用期间汇总，明细按日期从晚到早排列（同日保持录入顺序）。打开导出设置时固定本次数据快照，两种格式共用完整明细；PDF 自动分页。历史报告随补录更新，不是已封存的历史快照。
- 开销按归属月份统计，允许后续补录；未来日期的开销暂不计入实际支出。部分月份缺预算时标注“已录入预算合计”及缺失月份，不推算全年预算或余额。
- 缺失人数、时长或金额保留“待补”及条数；部分已知时仅合计已知值，全缺失时不显示为零。AI 分享月通过已关联的培训记录计入培训总量，分享活动列表不再叠加一次。

- 培训场次记录“人数”，多场汇总记为“参训人次”；培训人时为每场人数乘时长后相加。
- 咖啡开小灶按期显示：首页在已登记场次日期全部过去后撤下本期，项目进展标为“本期已结束”，培训台账与月报、年报保留历史；登记当天或未来的新一期后自动恢复首页展示。日期待补时不自动判为结束。
- 未回收数值保存为 `null`。明确填写的 0 是真实零值；旧广播站中无法确认的 0 显示“待核对”。缺失值不进入平均率。
- 广播站各期保存自己的总人数；新一期不自动带入，只有点击“沿用上一期总人数”才复制并提示核对。
- 分享月使用持久关联 ID 更新培训记录。改日期或期数仍更新同一场，未完整回收人数与时长时不新建虚假的零值场次。
- 金融期次统一使用 `published`（兼容历史 `workflow.publish/data`）判定是否发布。查看/下载率分别根据本期回收值计算；缺少历史分母时保留原始已报告比例。
- 没有预算与预算为零分开处理。开销可独立登记，未设预算不显示超支或余额结论。
- 云端写入先比较版本并合并不同记录的改动；同一记录发生冲突时停止提交，保留本机副本并提示处理。
- AI 分享月的场次 = 分享月模块记录 + 培训记录中项目为“AI 分享月”（含旧格式“AI分享月(第N期)”）的场次。同日且同主题的记录视为同一场，只计一次；总览、项目进展、分享月面板和月度总结都按这一口径统计。
- 在分享月模块保存一场已在培训记录里手工登记过的分享时，会关联那条培训记录而不再新建；分享月的人数或时长未填齐时，不改动那条培训记录。
- 金融期次的已读或下载人数大于本期总人数时，状态显示“已发布 · 待核对”，比率显示“待核对”：说明总人数需要复核，不是数据未回收。

## 功能开关

- 预算：没有任何预算记录时，预算计划、预实对比和首页的预算提示都收起，只显示开销。要启用，把 `index.html` 里的 `SHOW_BUDGET` 改成 `true`，或在工具里导入含预算的数据。
- 金融小百科第一季已结项，「记一笔」菜单不再提供新一期；台账里的历史 12 期照常查看并计入报告。
- 顶栏的「月度 OKR」「PDF」只在工作总览、月度 OKR、年度总结三页显示。
